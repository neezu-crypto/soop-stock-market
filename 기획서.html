1서비스 개요

SOOP STOCK 거래소는 SOOP(숲) 스트리머를 하나의 "종목"으로 삼아, 유저가 가상 자산으로 매수·매도하며 시세 변동을 즐기는 웹 기반 모의투자 서비스입니다. 실제 화폐가 오가지 않는 엔터테인먼트 목적의 팬 참여형 미니게임이며, Firebase Realtime Database를 백엔드로 사용해 모든 유저에게 실시간으로 시세·랭킹이 동기화됩니다.

  • 플랫폼: 단일 페이지 웹앱 (Vanilla JS + Firebase, 정적 호스팅 / GitHub Pages)
  • 대상: 스트리머 팬덤 커뮤니티, 익명 방문자 포함 누구나 즉시 참여 가능
  • 수익 모델: 배너 홍보(우측 랭킹 배너, 차트 하단 광고 배너) 판매

2핵심 컨셉

📈 실시간 가상 시세

매수/매도 체결마다 가격에 즉시 영향(시장 충격)을 주는 방식으로, 실제 주식시장과 유사한 체감을 제공합니다.

🕯️ 분봉 캔들차트

체결 데이터를 1분 단위로 집계해 Chart.js 금융 차트로 시각화, 기간/분봉 단위를 유저가 선택할 수 있습니다.

🏆 실시간 랭킹 · 배너

거래량 상위 5개 종목을 주기적으로 집계해 노출하고, 스트리머 홍보 배너로 수익화합니다.

4주요 기능

4.1 종목 리스트 & 검색

  • 전체 종목을 실시간(onValue) 구독하여 가격 변동 시 카드 UI를 자동 갱신
  • 검색창 입력 시 종목명 기준 즉시 필터링
  • 등락률에 따라 상승(빨강)하락(파랑) 색상 구분, 카드 내 스파크라인으로 최근 추세 시각화

4.2 캔들 차트

  • 체결 시마다 candlesticks/{stockId}/{분단위 timestamp}에 OHLCV 데이터 기록
  • 기간 탭(예: 10분/1시간 등)과 분봉 단위 탭을 조합해 조회 범위를 조정
  • 최대 360분 데이터만 보관, 이전 데이터는 주기적으로 삭제되어 DB 용량 관리
  • 차트 호버 시 캔들 정보(시가/고가/저가/종가/거래량) 툴팁 표시

4.3 랭킹 시스템

  • 거래 발생 시 거래량 변동치를 누적(디바운싱, 30초 간격)한 뒤 서버에 일괄 반영해 쓰기 횟수를 절약
  • 집계된 TOP5는 rankings/top5에 저장되어 모든 유저에게 동일하게 노출

4.4 홍보 배너 / 광고

  • 랭킹 배너: 스트리머 홍보 이미지 + 노출 기간(D-Day) 설정, 기간 만료 시 자동 제외
  • 차트 하단 배너: 720×150px 규격의 별도 광고 슬롯 (chartBanner 노드), 랭킹 배너와 별도 운영/과금

5거래(매매) 로직

모든 매매는 Firebase runTransaction으로 원자적으로 처리되어 동시 거래 시 정합성을 보장합니다.

가격 결정 공식

  • 시장 충격(impact): 0.001 × 수량
  • 스프레드(spread): 0.0005
  • 매도 수수료(fee): 0.3%
  • 매수가 = 신규가 × (1 + spread), 매도가 = 신규가 × (1 − spread)

제한 · 검증

  • 거래 쿨다운: 1초 (연속 클릭 방지)
  • 매수 시 잔액 부족 검증, 매도 시 보유 수량 부족 검증
  • 체결 시 평단가(avg) 자동 재계산, 매수/매도 효과음 재생

체결 후에는 유저 데이터(users/{uid}) 갱신 → 분봉 캔들 업데이트 → 랭킹 반영(디바운스 예약) 순으로 후처리가 이어집니다.

6인증 · 관리자 모드

  • 일반 유저: 별도 로그인 없이 Firebase 익명 인증(signInAnonymously)으로 자동 참여, UID 기준으로 자산/보유 종목이 저장됨
  • 관리자 인증: Ctrl + Enter 입력 시 구글 로그인 팝업 실행 → 로그인 계정이 관리자 이메일과 일치하면 관리자 모드 활성화
  • 관리자 모드 활성화 시 점검 오버레이를 스킵하고 정상 서비스 화면으로 진입 (점검 중에도 관리자 본인은 접속/점검 확인 가능)
  • 관리자 계정은 별도 관리자 페이지(soop-stocks-admin-gate16103.html)와 동일 계정을 사용 — 종목 시세 강제 조정, 랭킹 재계산, 배너 등록, 비활성 유저 정리 등은 해당 페이지에서 수행
참고 — 관리자 판별은 클라이언트 단에서 이메일 문자열을 비교하는 방식이므로, 실제 데이터 쓰기 권한은 Firebase 보안 규칙(database.rules.json)으로 별도 검증되어야 합니다.

점검 오버레이 노출 (전면 차단)
  • 점검 플래그(LONG_MAINTENANCE)는 코드 상수로 on/off — 장기 점검 시 true로 설정
  • 점검 중에는 일반 유저의 실시간 데이터 구독·거래 로직 자체가 실행되지 않아 서버 부하 및 오작동을 원천 차단
  • 점검 안내창에는 사유 안내와 개발자 방송국 바로가기 버튼 제공

8데이터 구조 (Firebase Realtime Database)

경로설명
stocks/{id}종목별 현재가, 최근 가격 히스토리, 거래량, 등락률
users/{uid}유저 보유 현금(cash), 보유 종목(stocks: qty/avg), 최근 거래 시각
candlesticks/{stockId}/{분단위 timestamp}OHLCV 분봉 데이터 (최대 360분 보관)
rankings/top5거래량 기준 상위 5개 종목 (디바운스 배치 반영)
presence/count, presence/users/{uid}실시간 접속자 수 집계 (접속 시 등록, onDisconnect로 자동 정리)
chartBanner차트 모달 하단 광고 배너 이미지/링크
